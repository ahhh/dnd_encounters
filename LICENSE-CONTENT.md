# Content licences

This project bundles two content packs under different licences. Every entity in
the registry carries its own `{packId, sourceId, version, license}`, and every
generated sheet records which packs contributed to it.

## srd51 — CC BY 4.0

This work includes material from the System Reference Document 5.1 ("SRD 5.1")
by Wizards of the Coast LLC, available at
<https://dnd.wizards.com/resources/systems-reference-document>. The SRD 5.1 is
licensed under the Creative Commons Attribution 4.0 International License,
available at <https://creativecommons.org/licenses/by/4.0/legalcode>.

The pack is a curated subset of the SRD, restructured into machine-readable
mechanics. No non-SRD content is included.

## openflavor — CC0 1.0

Backgrounds, name tables, personality tables and NPC archetypes written for this
project and released under CC0 1.0. Not derived from any published setting. Free
to edit, extend, or replace.

## Generated content

Creatures produced in `variant` or `generated` mode are original game content
created by this tool. They carry an explicit notice on the sheet and in every
export, and are never presented as official D&D creatures.

## Code

The code in `src/` and `tools/` is the author's own and is not covered by either
content licence.
